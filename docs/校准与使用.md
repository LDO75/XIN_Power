# 当前版本校准与使用

## 首次使用

1. 按硬件补丁说明核对R316、R292及输出理想二极管旁路。
2. 使用稳定输入。28V PD供电要确认适配器与诱骗协议支持该档位；小电流自动休眠会影响调试。
3. 有线/无线手动选定系统串口，连接后核对固件6.2.3、硬件V2、协议5、3.2～32V范围。
4. 首先读取原校准表，不执行CAL RESET或全片擦除。
5. 新阻值/新输出通路下，空载用可信万用表重新确认各点，再接实际负载。

## 校准

16点：3.2、3.3、3.5、3.8、4、4.2、5、7.2、8.4、9、12、18、20、24、28、32V。

选择点位后手动调DAC。升压降低DAC码，降压提高DAC码；接近目标时单码调整。输入**万用表实测值**，点击采集并保存，等设备确认及读回一致后再继续。每个点独立生效，保存后输出关闭。

校准期间PI关闭，DAC固定。若DAC没有变化而万用表电压继续变化，先检查硬件工作点和参考供电，等待真实稳定再采集。没有“只要按钮成功就代表输出稳定”的假设。

schema5按名义电压迁移旧schema3/4匹配点。硬件标记0x4991对应当前阻值；不兼容阻值配置的表不能直接沿用。旧表12个匹配点可保留，新增3.2/3.5/3.8/4.2V需实测。

## 常用功能

- 主界面设定电压、过流阈值、开启/关闭输出；右滑进入左侧设置页。
- 超过电流阈值关断锁存，清除故障不会自动开启。
- 默认屏幕1分钟休眠，可选关闭/30/60/120/300/600秒；休眠不停止供电。任意触摸唤醒，下一次触摸才执行操作。
- 遥测默认25Hz；中文状态摘要最多5条/秒只是显示节流，实际数据以完整记录/速率统计为准。
- 输出关闭仍显示真实残压。Vpp是低频采样极差；切换设定后重新等待稳定并收集1秒窗口。

## PI边界

6.2.3在3.2～32V全范围、误差不超过±100mV时PI微调，超范围暂停并保持当前码。校准/换设定/关闭/故障会重置；只补偿INA测量点上的电压，不补偿该点之后的外部线损。

参数Kp0.20、Ki2.00/s、D0为待实板整定的初始值。DAC每码约14.33mV，不能承诺任意目标1mV精度。持续大于100mV的压降不在当前外环纠正范围。

## 实测建议

优先记录3.2/3.3/5V空载与加载/卸载，再扩展到12/24/32V。记录输入、负载、目标、万用表、电压波形、DAC和PI状态。短路/过流验收需量到真实电流及关断时刻，INA软件读取不能代替微秒级硬件比较器。高功率测试要同时记录输入限流与热状态。
