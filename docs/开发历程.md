## 四条调试主线

### 校准

从“目标/稳定条件限制”回归“人工DAC与万用表实测关系”。随后修复单点资格、Flash保存、读回、上位机显示以及不同schema/点位ID迁移。R316变更必须同步曲线标签。

### 低压硬件

3.5V附近跳变 → 分段观察前后电压 → 反馈阻值与DAC表匹配 → SRC供电方式改变后漂移不同 → 断开SRC周期波动消失 → 最终旁路该输出级。用户提供的测量支持缩小故障范围，没有证明理想二极管芯片内部唯一机制。

### 保护与调度

误判低电压空载SHORT → 以实际过流为短路关断依据 → 保留输入欠压/过压/过温/监测失联 → 1kHz影响交互 → 500Hz采样、电流优先、SPI让出服务、DMA发送。

### 产品交互

屏幕主界面精简 → 设置页中文 → 清黑/顶栏重绘 → Vpp稳定后重新统计 → 屏幕休眠不改变输出 → PC手动选连接方式、中文日志、后台批处理 → 默认25Hz与有限同端口恢复。

## 最新验证的解读

离线C检查覆盖保护、存储、协议、重试与UI状态；Python检查覆盖数据包、命令、升级状态机、串口选择/恢复和页面加载。假设一阶模型用于验证控制实现的边界行为，不是实际SC8701/MOS电路的SPICE模型。

实板曾完成不同节点的校准与低压观察；最新公开字体构建没有因此被标为“完成32V8A、所有负载、长期老化验收”。当前范围和硬件状态请以README/硬件补丁为准。
