# 构建与下载

## 1. 工程顺序与工具

从`firmware/current`开始：01_Bootloader → 02_Application → 03_Factory → 04_Recovery说明 → 05_PC_Tool。

- 已使用工具链：Keil MDK / Arm Compiler 6.24；Puya.PY32F4xx_DFP.1.0.8；实际芯片PY32F403C1DT6，工程设备组PY32F403xD。
- Python 3环境；上位机依赖见05_PC_Tool/requirements.txt，安装pyserial和PySide6_Essentials。
- 字库重生成需Pillow；随源码提供OFL思源黑体、Oxanium字体及生成工具。
- 固件主机检查使用GCC和PowerShell；Keil链接后的RAM/栈预算需Python检查。离线检查不打开串口。

## 2. 内部Flash与外部Flash

| 区域 | 地址与长度 |
|---|---|
| Bootloader | 0x08000000，0x8000字节 |
| APP | 0x08008000，0x58000字节 |
| 内部Flash终点 | 0x08060000 |
| RAM | 0x20000000，0x10000字节 |
| W25暂存/回退 | 0x00000000 / 0x00080000，各0x80000 |
| 升级元数据 | 0x00100000 / 0x00101000，各4KiB |
| 设置/校准保留区 | 0x01FFC000～0x01FFFFFF |

独立Bootloader来自留存的5.9.3完整工程，升级布局/硬件ID/元数据schema沿用当前APP的兼容定义，比较结果见发布验证。未把旧Factory HEX当作新版本完整镜像。

## 3. 编译

已有Bootloader时只需要APP。在工程目录运行（按本机路径修改参数）：

```powershell
./build_firmware.ps1 -KeilPath 'C:/Keil_v5/UV4/UV4.exe' -Python python
```

也可分别用Keil打开：

```text
01_Bootloader/MDK-ARM/XIN_Power_BL.uvprojx
02_Application/MDK-ARM/XIN_Power.uvprojx
```

Bootloader输出`01_Bootloader/MDK-ARM/Objects/XIN_Power_BL.hex`；APP输出`02_Application/MDK-ARM/Objects/XIN_Power.hex`。APP脚本会检查零错误/零警告及栈预算。默认下载算法需选择官方器件包对应容量，不要用其他容量的通用算法代替。

公开中文位图已经生成。如需重生成：

```powershell
python 02_Application/Tools/generate_heiti_font.py
python 02_Application/Tools/generate_oxanium_font.py
```

## 4. 空片安装与APP更新

空片先生成完整合并HEX：

```powershell
python 03_Factory/make_factory_hex.py 01_Bootloader/MDK-ARM/Objects/XIN_Power_BL.hex 02_Application/MDK-ARM/Objects/XIN_Power.hex 03_Factory/XIN_Power_FACTORY_SWD.hex
```

脚本检查HEX校验、BL/APP地址、向量表及重叠。SWD首次安装下载Factory镜像，核对运行后再做校准。

**已有兼容Bootloader的板子只刷APP。** APP基址0x08008000，不覆盖前32KiB。保留W25Q256；不要为了升级执行全片擦除、修改读保护或CAL RESET。用上位机在线升级时选择APP HEX/BIN，等待上传、校验、应用和重启确认；BL搬运阶段保持供电。

## 5. 上位机源码和打包

进入05_PC_Tool，运行`run_windows.bat`，或安装requirements后按该脚本的Python入口运行。打包用`build_windows.bat`，其中PyInstaller等构建工具由脚本管理。

已有Windows EXE也放在downloads目录；与源码同为6.2.3。EXE不会因为本次固件换字体而自动修改通信版本。实时接口设置文件只在需要本机接口时使用，不含固定端口和个人会话数据。

## 6. 检查入口

```powershell
./tests/run_620_checks.ps1
```

上位机在05_PC_Tool/tests目录执行：

```powershell
python -X utf8 -m unittest test_620 test_622 test_623 -v
```

固件检查会产出UI像素预览和数据包向量，上位机测试使用它们。package_623.py为原交付包校验入口，其对原构建日志和文件布局有固定要求；开源包使用仓库发布说明及SHA256SUMS，不应直接套用原打包脚本声称验证通过。
