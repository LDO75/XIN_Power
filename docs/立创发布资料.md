# 立创项目发布资料

- 标题：**XIN Power｜PY32F403＋SC8701 3.2～32V数控可调电源**
- 摘要：基于PY32F403与SC8701，支持触摸调压、16点电压校准、有线/蓝牙上位机及在线升级。提供原理图、ABS-CF10打印外壳、散热与装配说明、烧录与校准步骤，以及约95W连续20分钟负载记录。
- 标签：数控电源、SC8701、PY32F403、INA226、Type-C、触摸屏、蓝牙。
- 正文：[立创开源文章](立创开源文章.md)。
- 源码：[LDO75/XIN_Power](https://github.com/LDO75/XIN_Power)。
- 原项目：[cyxsnbb666 Type-C可调电源](https://oshwhub.com/cyxsnbb666/typec-adjustable-power-supply-wi)。
