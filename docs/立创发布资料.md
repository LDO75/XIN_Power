- 标题：**XIN Power｜PY32F403＋SC8701 3.2～32V数控可调电源**
- 摘要：基于PY32F403与SC8701的V2补丁电源，支持3.2～32V、0.1～8A过流设定、16点DAC校准、触摸屏、有线/蓝牙上位机和在线升级。本文公开完整工程及关键历史版本，记录低压调试、SRC供电漂移、输出级旁路、500Hz测量调度、二进制DMA通信和小误差PI微调的开发过程。
- 标签：数控电源、SC8701、PY32F403、INA226、Type-C、触摸屏、蓝牙、开源硬件。
- 源码链接：https://github.com/LDO75/XIN_Power
