# XIN Power V6.2.3 — V2补丁硬件，3.2–32V / 最大设定8A

## 下载与使用

- `XIN_Power_V6.2.3_APP_USB_BT.hex`：APP，地址0x08008000，不含Bootloader。
- `XIN_Power_Studio_V6.2.3.exe`：新版Windows上位机，含25Hz默认回传和有线同端口恢复。
- `XIN_Power_V6.2.3_Source.zip`：Keil APP工程、Qt上位机、协议和回归检查源码。
- `realtime_settings.json`：放在EXE旁边开启本机实时读取/控制接口；不会自动连接COM14。

沿用已经安装的Bootloader。升级应用时保留W25Q256与原Bootloader，不做全片擦除或CAL RESET。新版上位机能读取旧协议4固件并上传新版APP；新版APP的常规通信采用协议5。普通旧串口助手发送INFO后也可使用兼容文本通道，文本回传最高10Hz。

本次添加全量程小误差PI微调，保留屏幕休眠、25Hz回传与有线恢复，未连接电源串口、烧录或带载实测。首次烧录后请先核对固件6.2.3、硬件V2、采样周期2ms和校准表。

## 硬件基准

| 项目 | 本版基准 |
|---|---|
| R274 | 100kΩ |
| R314 + R315 | 7.5kΩ + 120Ω = 7.62kΩ |
| R316 + R317 | 4.99kΩ + 120Ω = 5.11kΩ |
| R292泄放 | 用户确认实装1.8kΩ |
| 输出理想二极管 | 用户确认MOS D/S已短接旁路，后续版本采用此基准；输出无此级防倒灌功能 |
| DAC参考 | 3.000V，MCP4725，4096码比例 |
| 调压方式 | 正常输出先用校准点线性映射，在实测误差±100mV内PI微调；手动校准固定DAC，不做恒流 |

8A是电流设定上限，不表示32V可以连续输出8A。保留输入4.8A过流阈值；28V输入对应约134.4W输入功率，输出还受损耗和硬件能力约束。

## 固件界面与任务频率

- INA226每2ms轮询，目标500Hz，保持0x4097连续转换、332µs母线/分流转换、平均1次。芯片完成标志CVRF确认后才算新样本。
- 输出INA电流优先读取并解算，马上检查过流，然后读取电压与输入通道。单路电压读取失败或另一颗INA失败，都不会屏蔽已读到的有效过流电流。
- 屏幕20ms更新，目标50Hz，只传变化的数字区域；SET/OCP栏未变化时不重复发送。LCD分段发送期间继续让出前台给采样和保护；没有在中断里进行阻塞I²C。
- 串口常规遥测40ms一次，目标25Hz，双UART发送使用DMA，收命令仍使用中断字节环形队列。
- 主界面中间栏左侧“波动 Vpp”、单位mV，右侧功率。设备波形页面已删除。主界面右滑打开左侧设置，设置页左滑返回。
- 设置页中文黑体，含亮度、蜂鸣器、方向、电流零点校准、屏幕休眠、版本。主界面其余布局保持原样。

“波动 Vpp”取最近1秒有效的原始校准后输出电压最大值减最小值，最多500个采样，未经过显示低通；过期/失联时显示无效。它是低频采样波动，不是开关频率纹波测量。零点电流与R292泄放电流修正保留，过流判断使用扣除泄放前的电流。

这些是调度目标，实际速度由总线、触摸、Flash等操作决定。上位机日志/CSV同时记录实测采样Hz与最大样本间隔，不以25Hz遥测声称500Hz采样始终达标。INA测量不是硬件比较器，不能承诺2ms内必然完成短路关断。[INA226时序资料](https://www.ti.com/lit/ds/symlink/ina226.pdf)。

## 基本保护完整列表

| 保护 | 判定 | 动作 |
|---|---|---|
| 输出过流/短路大电流 | 有效电流大于用户设定（0.1–8A）；绝对备用上限8.5A；校准前/后电流取较大值 | 首个有效越限读数关断并锁存，IOUT_OC |
| 输入过流 | 大于4.8A | 首个有效越限读数关断并锁存，IIN_OC |
| 输入欠压 | 小于4.0V持续200ms | 关断并锁存，VIN_UV |
| 输出绝对过压 | 大于33.0V | 有效测量判定后关断并锁存，VOUT_OV |
| 输出相对过压 | 大于参考电压 + max(300mV,参考的10%)持续100ms | 关断并锁存，VOUT_OV |
| 过温 | 有效温度大于等于80℃ | 关断并锁存，OTP |
| INA持续失联/数据冻结 | 输出开启时完整新样本中断500ms（默认采样周期下） | 关断并锁存，MON_OFFLINE |

清除故障后仍保持输出关闭，需要手动再次开启。没有低电压SHORT判据，没有50mA门槛，没有额外启动短路延时，没有功率限制、恒流控制或自动恢复输出。温度传感器无效时沿用原逻辑，不新增NTC失联故障。

手动DAC校准允许输出电压与点位目标不同，因此此期间暂停相对过压；绝对33V过压、过流、输入欠压、过温、INA失联仍保留。DAC微调仍只有12位码范围与写入成功检查，不要求测量先贴近目标才能保存。

降压时相对过压参考按R292×输出电容量的RC上界下降，不能无限停留在旧目标。估计输出电容400µF（板内名义约333µF加容差），R292=1.8kΩ，τ=720ms；更快的真实下降也可降低参考。外接很大电容会改变放电时间，不能把此估算视为所有负载的实测保证。

## 校准表

新表schema5、16点，ID按电压升序：

`3.2、3.3、3.5、3.8、4.0、4.2、5、7.2、8.4、9、12、18、20、24、28、32V`。

选点 → 微调DAC → 输入万用表实测 → 采集并保存。每个点独立保存、保存后关闭输出，立即用于映射，无需等16点全部完成。上位机必须收到确认并读回相同实测值和DAC才显示保存成功。没有实测点的区间先使用现有邻点/理论斜率，不代表这些区间已经精密校准。

已有schema3/4、硬件标记0x4991的表按“名义电压”迁移，绝不沿用旧ID含义：保留3.3、4、5、7.2、8.4、9、12、18、20、24、28、32V共12个匹配点；新增3.2、3.5、3.8、4.2V等待实测。旧2、3、3.6、3.9、4.5V点不再作为新表点位。启动迁移只读原记录；实际保存时才写新schema5双备份，保留测量校准系数。其他阻值配置的旧DAC标记不能混用。

旧设定低于3.2V时钳位到3.2V，保留电流设定，输出启动保持关闭。

## 上位机

左下角集中放置“有线USB/无线蓝牙”选择、端口、扫描、连接/断开、连接状态与固件版本。扫描只枚举系统端口，不逐个打开或自动换到蓝牙；连接时只验证用户选中的端口。无线显示Windows已经配对的蓝牙串口，未配对设备需先在系统配对。

后台接收/解包，界面每20ms批量更新；日志用中文解算摘要，显示最近1000条，状态摘要5条/秒，后台完整记录收到的全部数据，默认25Hz。记录使用后台缓冲写盘；CSV保留真实电压、DAC、CE、波动、采样Hz等。清空显示不会删除后台记录。实际日志位于系统临时目录XINPowerStudio，导出使用完整已落盘记录。

正常模式仅一条命令等待确认；超时重试使用同一序号和原字节。固件缓存最近4条请求的完整响应，重复STEP/CAPTURE不再次执行；序号相同但参数不同拒绝执行。OUT OFF/停止校准走优先发送队列，不能被一串查询拖在后面。

## 6.2.1显示补丁

- 完整切页与显示方向重绘：先全屏清黑，再填充新页面；返回主界面强制完整重画顶栏，不依赖VIN/TEMP变化。普通50Hz刷新仍为局部更新。
- Logo绘制前也清黑。Vpp/功率局部刷新使用与完整面板相同的背景合成，保留圆角边框。
- 二进制INFO、文字INFO和设置页的版本号统一使用共享定义，设备均报告6.2.3。
- 以实际输出使能和已应用的映射DAC基准检测调压，手动校准使用实际DAC，包括上位机、屏幕与校准微调；暂停Vpp取样并清空旧窗口，保留最后一个有效Vpp。首次尚无有效值时显示“-- mV”。
- 变化后至少等待200ms，再要求连续400ms电压采样跨度不超过20mV；稳定后重新收集1秒数据，才更新Vpp。升降压期间不会把旧、新电压混入同一个窗口。持续调压会重新开始等待。
- 稳定准入只在输出/DAC变化或采样恢复后运行；恢复统计后，真实波动即使大于20mV也照常显示。采样失效或间隔超过20ms时Vpp失效，恢复后重新确认稳定和收集窗口。
- 以上仅改变Vpp统计，500Hz电流读取和关断保护照常运行，DAC校准映射、故障阈值、协议5和Flash校准地址保持兼容。短接理想二极管不会被软件模拟成输出隔离开关。

每次切页增加一次全屏SPI传输，可能短暂看到黑色过渡。清黑能处理遗漏像素；若实机清黑后仍存在残影，需再区分屏幕图像残留、驱动参数和光学反光，离线栅格测试不能证明液晶物理残留已经消失。

## 6.2.2屏幕休眠与通信补丁

- 默认休眠1分钟。在设置页向上滚动找到“屏幕休眠”，点卡片依次选择：关闭、30秒、1分钟、2分钟、5分钟、10分钟。
- 无触摸达到时限后先关闭背光并清屏为黑；供电输出、DAC、采样、保护、串口和校准任务继续。任何有效触摸唤醒当前页面，重绘完成再恢复此前亮度。
- 唤醒的一整次按下/移动/抬起不执行按钮、滑动或调压操作；下一次触摸才操作界面。触摸失联时不主动休眠，以免无法唤醒。
- 时限修改即时生效。设置schema3使用原记录的保留字节，兼容schema1/2并默认1分钟；记录布局和电压校准Flash地址不变。设置写盘仍等输出关闭后进行，不为了保存时限主动关闭电源。
- 两个串口分别默认40ms/25Hz，INFO报告实际配置周期；RATE接受20–5000ms，改变命令所在通道。上位机可选25/10/5/50Hz。文本兼容通道最高10Hz。500Hz采样、50Hz屏幕刷新不变。
- 新上位机连接6.2.2及以上时发送LOG RATE 40和STATUS，读取设备真实状态。有线系统读写异常最多恢复同一端口5次，间隔1.8秒；手动断开、改选端口或连接方式可取消。恢复不重发旧连接的开关输出、调压、采集保存等操作。
- 命令缺少最终确认时保留串口接收，提示操作结果未知。正常的同序号重试仍保留，最终超时之后不继续执行重试。
- 日志摘要每秒最多5条，只是显示节流；完整数据照常记录。实际25Hz需结合上位机回传速率和完整记录确认，不能用可见日志行数判断。

有线断链记录来自Windows串口API的“拒绝访问”，并非CRC错误或固件协议超时；降低回传和自动恢复不能证明设备/驱动故障根因已经消除，详见《有线断链分析.md》。未打开实机串口或执行烧录。

## 6.2.3全量程小误差PI

3.2–32V正常输出都可微调。实测误差定义为设定mV减校准后未经过显示滤波的输出mV；进入-100至+100mV（含边界）后计算PI。超过100mV时停止积分/调码，保持当时已应用DAC，不跳回映射值。重新进入范围时无突变地重建积分起点。

这是误差准入范围，不是总补偿幅度上限，不保证负载突变的瞬态电压永远在±0.1V。若压降超过100mV且硬件不能自行回到范围，本版按用户要求不会主动追赶。

Kp=0.20、Ki=2.00/s、Kd=0；这是待带载验证的试验参数。每个新INA样本最多计算一次，实际dt积分；8mV死区、0.65 DAC码决策滞回、每次最多1码且写入间隔至少10ms，DAC范围0–4095，饱和时回算积分。没有要求每2ms都写DAC。正常闭环微调不会冻结Vpp，实际波动照常统计。

更改电压设定、关闭输出、故障关断、进入手动校准时重置PI；手动校准不自动调DAC、不改已保存校准点。采样无效/间隔超过20ms暂停微调，原500ms监测失联保护仍保持。过流与其他原保护优先处理，阈值不变。

上位机诊断与中文日志显示PI微调/暂停和误差mV，CSV最后追加两列。PI基础参数集中在power_config.h，本次没有复用旧6.0.6的连续全范围PID调参接口。

编译、模型及边界验证见QA_6.2.3.md和PI控制说明.md；没有实机连接或负载调参。
