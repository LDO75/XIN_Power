# 6.2.3小误差PI控制说明

## 用户确认的边界

范围3.2–32V；误差进入±0.1V才启用PID微调。实现采用PID的PI形式，D项0。测量点仍是现有输出INA226，不能补偿测量点之后的外部接线压降。正常起步使用现有16点校准映射，手动校准仍固定DAC。

| 状态 | DAC行为 |
|---|---|
| 开启输出/改设定 | 应用新的校准映射码，重置积分 |
| 有效新样本且误差≤100mV | PI微调，误差≤8mV时保持 |
| 误差>100mV | 保持已应用码，暂停PI；回到范围无突变恢复 |
| 样本失效或dt>20ms | 暂停PI、不把停顿时间累积进积分 |
| 关闭/故障 | 先关闭CE，再停车DAC；PI重置 |
| 手动校准 | 固定人工DAC，PI关闭，不自动学习/改校准表 |

## 方程与实现

e=设定电压−INA校准后快速电压（mV）。当地DAC斜率g（mV/码）用同一校准映射附近区间估计，端点用单边区间，无有效斜率则使用原电阻公式。

P=−Kp×e/g；I候选=I−Ki×dt×e/g；DAC连续命令=映射基准+I候选+P。负号对应本硬件DAC升高使输出降低。

Kp=0.20，Ki=2.00/s，Kd=0。每个新样本最多计算一次，目标500Hz，采样与限流判断先于PI。LCD绘制让出前台时也服务PI，无阻塞中断I²C。样本序号不变不重复积分。
进入误差范围时令I=已应用DAC−基准−P，防止比例项造成切换跳变。DAC裁剪到0–4095、连续命令限制在当前码±1内，再反算I；写入失败不提交积分。整数码需连续命令偏离当前至少0.65码才变化；写入至少间隔10ms，减少量化来回跳码。

按电阻理论每码约14.33mV，实际采用校准区间估计，不能承诺1mV调节分辨率。8mV死区和0.65码滞回用于限制噪声/量化引起的跳码，仍需实际噪声与负载验证。没有±100mV总补偿限制，只有用户指定的误差准入；DAC饱和时无法保证回到目标。

## 理论与模型的范围

把SC8701已经闭环的DAC到输出响应近似成归一化一阶G(s)=1/(1+τs)，软件PI为C(s)=Kp+Ki/s。连续模型特征式为τs²+(1+Kp)s+Ki=0，τ>0时这些参数满足二阶稳定条件；τ=200ms时阻尼约0.95。该推导不包含实际功率级的额外极点、轻载模式切换、采样/I²C延迟和MOS寄生。

真实C控制器另在216个离散一阶模型组合测试：3.2/17.6/32V，τ=5/20/80/200ms，纯延迟0/10/20ms，执行器增益0.5/1/1.5倍，±80mV负载扰动、±2mV测量噪声，加载后卸载。结果及最大末端误差见验证记录/model_summary_623.json；这是假设模型的结果，不是SC8701实机测量，不能据此承诺所有负载稳定或无过冲。

数字环路的采样和执行延迟限制可实现带宽；软件外环应根据实测动态调整，500Hz计算频率不代表500Hz控制带宽。参考：[Microchip数字控制实现](https://developerhelp.microchip.com/xwiki/bin/view/applications/power/digital-power-converter-basics/implementation-of-a-control-loop/)、[TI数字环路设计](https://www.ti.com.cn/cn/lit/pdf/slua622)。

正常PI写码使用同一映射基准作为Vpp调压事件标识，因此不会每次微调都清空1秒波动窗口。换设定、开关输出、手动DAC步进仍按原稳定准入冻结/重开窗口，PI本身的真实波动不会被普通微调事件隐藏。

## 建议实测记录

先在3.3V、5V、12V、32V分别观察空载、加载、卸载，记录vfast、误差、DAC、PI状态、波动和采样间隔。重点区分误差越过100mV导致的暂停与闭环参数振荡；前者是本版明确的准入规则。大于100mV压降不会自动纠正，不应靠提高Ki解决。参数未经过该板实测整定。
