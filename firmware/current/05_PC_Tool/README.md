# XIN Power Studio V6.2.3

运行EXE或run_windows.bat。左下角选择有线/无线、扫描系统端口、手动连接。扫描只枚举，连接只打开选定端口；旧协议4支持兼容文本，新版协议5二进制。

默认25Hz/40ms，可选10/5/50Hz。固件6.2.3修复了RATE设置不控制二进制遥测调度的问题。界面50Hz批量更新，中文状态日志显示最多5次/秒；完整收到的遥测仍写入记录及CSV。连接新版固件会配置40ms并读取STATUS，不更改电源输出。

Windows串口读写异常恢复同一有线端口，最多5次、每次间隔1.8秒，不重发旧的输出、设定或校准命令。改选端口/连接方式/断开取消恢复。普通命令确认超时会报告结果未知并继续接收数据。

校准16点，3.2–32V/0.1–8A，直接DAC调压，超过电流设定关断。校准保存和旧表迁移说明见根目录README_下载与校准.md。休眠在设备设置页选择。

当前版本测试（在tests目录）：python -X utf8 -m unittest test_620 test_622 test_623 -v。历史test_603等面向旧表/旧范围，不能直接作为本版验收。打包：build_windows.bat。
无硬件检查：XIN_Power_Studio_V6.2.3.exe --smoke-test --smoke-output preview.png，离屏启动并退出，不连接串口或启动实时控制接口。

新增全量程±100mV误差内PI微调，日志/诊断显示PI状态及误差；CSV29列。校准期间保持人工固定DAC；旧连续PID页面/接口不适用。控制参数及限制见根目录docs/PI控制说明.md。
