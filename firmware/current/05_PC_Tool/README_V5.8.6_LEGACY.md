# XIN Power 上位机 V5.8.6

同一个上位机支持两种连接，并使用同一套命令和日志协议：

- USB 转串口：固件 USART1，PA9/PA10，115200 8N1。
- VG6328A 无线串口：固件 USART2，PA2/PA3，115200 8N1。

## VG6328A 在 Windows 中叫什么

VG6328A 是模块型号，不是出厂广播名。原厂默认名称为：

| Windows/手机看到的名称 | 类型 | 本工具是否使用 |
|---|---|---|
| `XLBT` | 经典蓝牙 SPP | 是，配对后生成 COM 口 |
| `XLBLE` | BLE GATT | 否，不会直接生成传统串口 COM |

Windows 应配对 `XLBT`。配对完成后，回到主界面点击“扫描”，等待程序通过 `PING`/`INFO` 识别设备；在端口列表中确认目标 COM 口，然后点击“连接”。扫描、选择和连接都在主界面完成，不必进入校准页。已知 COM 口时也可直接在主界面选择并连接。

蓝牙 SPP 可能在扫描探测后需要短暂释放端口；若首次连接失败，请等一两秒后对同一端口重试，并检查 Windows 中 `XLBT` 已配对且对应的传出 COM 口可用。不要选择仅提供 BLE 的 `XLBLE`。

界面内的“蓝牙连接向导”也包含同样的分步说明。

> 原厂资料给出的默认 UART 是 115200 8N1，默认同时开启 BLE 和 SPP。若要改名，模块需先进入 AT 模式；SPP 名称使用 `AT+SPNA...`，BLE 名称使用 `AT+LENA...`，设置后复位生效。普通设备控制命令不要直接当作模块 AT 通道使用。

## 直接运行

Windows 安装 Python 3.11 或更新版本后，双击 `run_windows.bat`。脚本只在本目录建立虚拟环境并安装依赖。

## 打包成单文件 EXE

双击 `build_windows.bat`，完成后得到：

`dist\XIN_Power_Console_V5.8.6.exe`

该 EXE 不要求目标电脑安装 Python。源码交付包不携带庞大的虚拟环境或预编译EXE；需要发布时，在Windows上双击`build_windows.bat`即可重现打包。

## 新版界面

- 深色仪器面板：输出电压、电流为主读数，输入、电功率、温度和设定值为次级读数。
- 主界面提供扫描、端口选择、连接和断开；协议探测通过 `PING`/`INFO` 确认真正的 XIN Power。
- 统一调试终端：TX、RX、ACK、错误和遥测帧采用固定颜色与毫秒时间戳。
- 链路状态：显示 USB/蓝牙类型、固件版本、协议版本和遥测新鲜度。
- 保留趋势图、原始命令、完整日志导出和 CSV 遥测记录；电压以三位小数显示。
- 同时显示用户设定限流和固件综合100W/输入能力后的有效限流。
- 设置页保留外部标准仪表参与的高精度电压两点校准，同时提供输出电流和 DAC 校准向导。

## 自动校准

请先确认电源板与固件匹配、参考源配置正确。连接后打开“设置 / 校准”，准备可信的万用表和电子负载，按向导依次完成：

1. 输出关闭时自动采集电流零点。
2. 设备自动设置 5V，输入万用表实际电压，可精确到 0.001V。
3. 设备自动设置 20V，输入万用表实际电压，可精确到 0.001V。
4. 设备回到 5V/2A，接入 0.5～1.5A 负载并输入实际电流。
5. 上位机自动计算电压/电流增益与零点、DAC 两点映射，关闭输出后写入 W25Q256 双备份校准区。

没有外部标准仪表时无法得到真实校准值；0.001V 是输入与显示分辨率，不代表整机已达到 1mV 绝对精度。向导自动化的是切换、采样、计算和保存过程。

## 固件命令

每条命令以回车或换行结束，不区分大小写：

| 命令 | 作用 |
|---|---|
| `PING` | 链路测试 |
| `INFO` | 固件与协议版本 |
| `STATUS` | 立即返回一帧遥测 |
| `SET V 5000` | 输出设定为 5000mV |
| `SET I 1000` | 软件限流设定为 1000mA，允许100～8000mA |
| `OUT ON` / `OUT OFF` | 开启/关闭输出 |
| `LOG ON` / `LOG OFF` | 开启/关闭当前通道日志和遥测 |
| `LOG RATE 500` | 遥测间隔，允许 100～5000ms |
| `CLEAR` | 请求关闭输出，使现有保护状态安全复位 |
| `CAL GET` / `CAL RAW` | 读取校准参数与未校准原始值 |
| `CAL SET V gain offset` | 设置输出电压 ppm 增益与 mV 零点 |
| `CAL SET I gain offset` | 设置输出电流 ppm 增益与 µA 零点 |
| `CAL SET DAC v1 c1 v2 c2` | 设置两个实际电压/DAC码点 |
| `CAL SAVE` | 输出关闭时保存校准参数到 Flash |
| `CAL RESET` | 仅将当前运行参数恢复默认值（未保存） |
| `HELP` | 输出命令摘要 |

结构化数据以 `@` 开头；原有人工诊断日志仍保持 `[INA226]`、`[POWER]`、`[NTC]` 等格式。兼容协议版本 3 的 `@TEL` / `@CAL` 字段，包括 `ilim`、`vvalid`、`ivalid` 和 `schema`。VG6328A 单个串口包不超过 255 字节，固件遥测帧已按该限制设计。

## 手动验收（不需要长时间测试）

1. 保持输出关闭，先用 USB：在主界面点击“扫描”，选择标记为 XIN Power 的 COM 口，再点击“连接”；确认状态变为已连接并出现实时读数。断开后重复一次。
2. 已配对 `XLBT` 时，用其 SPP COM 口重复“扫描 → 选择 → 连接”；无需打开校准页。若扫描识别到多个设备，逐个选择目标端口核对。
3. 在输出关闭时发送 `INFO`、`STATUS`，确认终端收到响应；随后用低风险设定值和合适负载短暂验证输出开/关及电压、电流读数。
4. 进入“设置 / 校准”，确认 5V 与 20V 电压步骤仍可录入三位小数。真正写入校准值前，须接好标准仪表并按提示完成全部步骤；仅检查界面时不要启动校准。
5. 如需持续负载试验，可开启 CSV 记录并导出日志；长时间稳定性测试请由用户在安全监护下自行进行。
