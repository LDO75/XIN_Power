# V6.2.0本机实时接口

把realtime_settings.json（enabled=true）放在EXE旁边。仅监听127.0.0.1，启动后地址和随机令牌写入live_api.json；不会自动连接设备。请求需Authorization: Bearer令牌。

- GET /v1/state：最新解算遥测、数据年龄、设备信息、epoch。
- GET /v1/events?after=游标：完整遥测、ACK、错误、故障等增量事件。
- POST /v1/voltage：mv为3200–32000整数。
- POST /v1/output：on为布尔值。
- POST /v1/telemetry-rate：ms只能为20，固定50Hz。
- POST /v1/connection：connected为布尔值，只操作上位机当前选择的端口。

POST需当前epoch。HTTP202表示排队，不等于设备执行成功；需等待对应ACK和后续状态。手动校准期间不允许该接口修改普通输出或电压。PID接口在直接DAC固件不可用。

JSONL通过后台线程缓冲写入，实际路径以live_api.json的record字段为准。vfast为原始校准后电压，vraw为未校准电压，iraw为未校准电流，vpp为最近1秒低频波动，hz/maxgap为内部完整采样实测频率/间隔，seq/samplet为完整采样序号/时间。cegpio是MCU引脚读回，不是SC8701脚模拟实测；dw/dwt为成功DAC写入计数/时间。
