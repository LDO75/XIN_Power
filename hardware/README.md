# V2硬件基准与补丁

当前源码用于PY32F403C1DT6、SC8701、MCP4725/REF3030、LMV321、双INA226、W25Q256、ST7789/CST836的V2板。功率MOS曾与原作者不同，输出理想二极管MOS实装型号曾为AGM6014A；最终该级D/S被旁路。

## 最终基准

| 器件/网络 | 当前配置 |
|---|---|
| R274，Vout至FB | 100kΩ |
| R314+R315，FB至地 | 7.5kΩ+120Ω=7.62kΩ |
| R316+R317，FB至缓冲输出 | 4.99kΩ+120Ω=5.11kΩ |
| R292泄放 | 实装1.8kΩ |
| DAC | 3.000V参考，4096码比例 |
| 输出理想二极管 | MOS D/S短接旁路，当前功率通路不依赖此级 |

早期曾从输入28V向MX16171的SRC飞线供电，用于解决输出侧供电下的低压/漂移问题。这是历史排查方案，不是当前版本必须保留的供电要求。旁路之后应避免仍连接控制器的残留供电/栅极网络干扰其他节点；具体拆改以实板连线为准。

## 输出关断与反向供电

CE关闭的是SC8701功率级。输出电容和板内供电/测量路径仍可能留下残压，固件回传实际测量值，不把关闭状态强制显示为零。旁路后的输出缺少原理想二极管提供的反向隔离；外部电池、另一个带电电源、并联输出需要专门的隔离/反向保护设计。

## 理论DAC关系

Vout=Vfb(1+Ru/Rd+Ru/Ri)−Va·Ru/Ri。按Vfb=1.22V估算：

- 4.99kΩ配置：Vout≈41.10−19.57Va，每码约14.33mV。
- 7.5kΩ配置：Ri=7.62kΩ，Vout≈33.24−13.12Va，每码约9.61mV。

这只表示反馈网络的直流数学关系，不能证明运放共模范围、功率级动态或输出后级都正常。更换阻值后需重校，不能混用旧硬件标记的DAC表。
